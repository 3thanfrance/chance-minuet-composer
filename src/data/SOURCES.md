# Music sources

The bundled 176 selectable measures originate from the public-domain historical game, digitized in JavaScript by [timmydoza/mozart-dice-game](https://github.com/timmydoza/mozart-dice-game) under the UNLICENSE.

Fourteen staff-level note/rhythm readings across thirteen measures are aligned to the Rellstabsche Musikhandlung edition transcription in [craigsapp/Musikalisches-Wuerfelspiel](https://github.com/craigsapp/Musikalisches-Wuerfelspiel), edited by Craig Stuart Sapp, Daniel Shanahan, and Mauricio Rodriguez (2021-06-12). The bundled selection excludes auxiliary ending ID 177.

The 11 × 16 table is independently checked against Princeton's published matrix. It uses measure 139 at total 4, position 10, correcting the duplicated 136 in the older JavaScript table.
